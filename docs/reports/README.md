# Phase reports

One report per build phase: what shipped, what the acceptance criteria were, whether they passed,
and — most importantly — what went wrong and had to be fixed.

The "defects found" sections are the point. They record bugs that were caught before release and
would otherwise have shipped looking correct, along with why they were invisible.
